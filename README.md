# wine-type-classification

## Overview
This project uses supervised machine learning to classify wine samples based on their chemical properties.

## Dataset
- Source: scikit-learn Wine dataset
- Samples: 178
- Features: 13 chemical measurements
- Classes: 3

## Methodology
1. Load and inspect the dataset.
2. Separate features and target labels.
3. Split data into training and testing sets.
4. Train a Decision Tree classifier.
5. Evaluate the model using accuracy, precision, recall, F1-score, and a confusion matrix.

## Tools
- Python
- Pandas
- NumPy
- Matplotlib
- scikit-learn
- Jupyter Notebook

## Results
Results will be added after running the notebook.

## Limitations
This is a small educational dataset. Performance on this dataset does not establish performance on wines from other regions, producers, or production years.
